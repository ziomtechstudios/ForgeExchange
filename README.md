# 🎮 Forge Exchange

## 📝 Description
* * **Genre(s):** Action / RPG / Casual Strategy / Time Management / Adventure
* * **Platform(s):** Android, iOS
* * **Target Audience:** Casual gamers who also want to be able to participate in hardcore activities.

## 🚀 Key Features
* **Feature 1:** Player can easilty transition between 2 main game modes: Time-mangement/casual strategy to Action/Adventure/Sandbox-RPG
* **Feature 2:** Procedurally generated terrain mixed with a mixture of static and hand made environments.
* **Feature 3:** Retro 16-bit style audio and graphic style with graphically 2.5D effects for depth.
